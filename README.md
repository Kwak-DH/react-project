# React 스터디 프로젝트

## 실행 방법
- pnpm install
- pnpm dev

## 기술 스택
- pnpm, Vite, React 19, TypeScript
- zustand, react-router-dom
- MUI, Tailwind CSS v4
- ESLint + Prettier

## 선택 이유
- styled-components 대신 Tailwind: styled-components가 유지보수 모드로 전환됐고, React 19와의 호환 이슈가 있어서 선택
- antd 대신 MUI: Tailwind와 함께 쓸 때 CSS Layer로 우선순위 정리가 가능하고, 국내 자료가 더 많음
